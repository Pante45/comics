Uso de Inteligencia Artificial

Durante el desarrollo del proyecto se utilizó ChatGPT como herramienta de apoyo para resolver dudas, revisar errores y orientar la programación en Django.

Se utilizó principalmente para apoyar el desarrollo del catálogo de cómics, las vistas, las plantillas HTML, el formulario de reservas, las validaciones y el control de stock.

También se utilizó para revisar el funcionamiento del proyecto y comprobar algunos requisitos de la evaluación.

Las sugerencias se fueron incorporando y probando durante el desarrollo del trabajo.
